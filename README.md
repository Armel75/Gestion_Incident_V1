# 🚨 Incident Manager

> Modern enterprise incident management platform built with a decoupled Frontend/API architecture to streamline incident reporting, categorization and operational analytics.

---

# Overview

Incident Manager is a web application designed to help organizations efficiently report, classify and monitor operational incidents through an intuitive user interface and a robust backend API.

The application centralizes incident management, improves traceability and provides decision-makers with actionable insights through an analytical dashboard.

This project demonstrates the implementation of a scalable enterprise application following modern frontend development practices and clean software architecture.

---

# Key Features

### 📌 Incident Reporting

- Create and manage operational incidents
- Capture detailed incident information
- Track incident lifecycle

### 🏷 Incident Categorization

- Organize incidents by category
- Standardize reporting
- Improve data consistency

### 📊 Analytics Dashboard

- Incident trends visualization
- Category distribution

### 🔗 API Integration

- Secure communication with REST API
- Real-time data synchronization
- Centralized business logic
